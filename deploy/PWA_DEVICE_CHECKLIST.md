# PWA 真机验收清单（波 V5 · 上线门槛合流）

> **执行时机**：VPS 部署（HTTPS 域名）后、进入真实使用前。与 PRD §18 上线门槛、
> 里程碑 §7「PWA 在 iOS+Android 等效环境验证」合流，一次收掉。
> **执行人**：持有一台 iOS + 一台 Android（或等效浏览器环境）。
> **回填**：逐项勾选并把结果记入 `docs/dev-guide/10_MILESTONE_PLAN.md` §5 波 V5 与 §7。

## 前置（VPS 侧，一次性）

- [ ] `docker compose -f deploy/docker-compose.yml build && up -d`，`alembic upgrade head` 到 0015
- [ ] HTTPS 生效（nginx.conf.example：证书 + SSE 透传 + 登录限速）——Web Push / Passkey 的硬前提
- [ ] env.sh：`WWSE_SESSION_SECRET`；模型 key；SMTP/企微/Server酱 任一真实渠道
- [ ] 可选启用：`WWSE_PASSKEY_RP_ID` / `WWSE_PASSKEY_ORIGIN` / `WWSE_PUSH_VAPID_*`

## A. 装机与登录（iOS Safari + Android Chrome 各一遍）

- [ ] 添加到主屏幕 → 独立窗口启动（无浏览器地址栏）；图标/名称正确（FR-PWA-001）
- [ ] 登录页正常渲染；登录成功进入首页
- [ ] Passkey：设置 → 安全与会话 → 注册本机 Passkey（系统弹生物识别）→ 登出 →
      用 Passkey 登录成功（`/settings/security` 列表 sign_count 递增）

## B. 首页与阅读（HOME-01 / REP / LIB-01）

- [ ] 首页 30 秒读完：问候+中文日期、数据状态条、总资产大卡、风险聚合条（有则显）
- [ ] 开市前/收市后报告可打开：降级标记、风险前置、footer（截至 · 来源 · 版本）
- [ ] 研究页：创建一个公司/行业任务 → 进度条推进（实时或轮询标记）→ 报告可读、
      引用清单含内容哈希、导出 MD/HTML 可下载（AC-05 抽样报告的生成侧）
- [ ] **抽样报告人工核**（AC-05 验收主项）：抽 2-3 份真实报告——关键财务数字能经
      引用溯源到正式披露文档；无来源结论带「推断/未证实」标注而非写成事实

## C. 弱网与离线（AC-08）

- [ ] 打开过一份报告后断网 → 重进该报告：显示「离线副本 · 缓存于 …」横幅，内容可读
- [ ] 断网 → 盘中问询页入口禁用并明示不可用；首页刷新按钮禁用
- [ ] 恢复网络 → 刷新至最新数据
- [ ] 退出登录 → 重新登录（或换用户）→ 离线报告中不含前一账号数据

## D. 交易闭环（TX-01/02/03 · ACC-01）

- [ ] TX-02 手工记录一笔买入 → 持仓页出现该标的、首页摘要更新
- [ ] TX-03 上传券商 CSV → 预览校验（错误行/重复行分区）→ 勾选确认 → 流水可见、持仓重算
- [ ] TX-01 类型筛选（如只看「分红」）与标的筛选生效；「加载更多」翻页正常
- [ ] ACC-01 账户显示「未对账」→ 确认对账 → 盘中问询不再因 `ledger_unreconciled` 暂停

## E. 盘中问询与多源冲突（CHAT-01 · 3.3）

- [ ] 交易时段问询一只持仓标的：建议卡 6 层信息 + footer 句式；降级时只显原因码
- [ ] （构造或等待）数据冲突发生 → DATA-01 出现冲突卡 + 相关标的建议暂停（`data_conflict`）
- [ ] SET-02 消解：选一个源 → 冲突转 RESOLVED → 建议恢复

## F. 通知与推送（SET-04 · 3.5）

- [ ] 设置 → 通知与隐私 → 浏览器推送「开启」（系统弹权限，允许）
- [ ] 触发一次研究任务完成 → 收到推送；**锁屏预览不含标的/金额/动作**（隐私模式 FR-NOTIFY-003）
- [ ] 点击推送 → 聚焦/打开应用

## G. 深色与观感

- [ ] 设置 → 外观 → 深色：全部访问过的页面无白底残留、文字可读
- [ ] 手机横竖屏切换布局不破；360px 小屏无横向滚动

## 回填

完成后在 `10_MILESTONE_PLAN.md` §5 波 V5 勾选并附日期；§7 上线门槛「PWA 在 iOS+Android
等效环境验证」同步勾选。发现的问题按页面 ID 记 issue/回填到本清单附录。
