# 交割单 PDF 导入手册

> 适用场景：券商 App 只能导出 PDF 交割单（无 CSV）时，将历史成交导入系统。
> 工具链：`backend/scripts/jgd_pdf_to_csv.py`（转换） + `backend/scripts/import_settlement.py`（导入）。
> 实测基线：2026-08 华泰交割单（51 页 / 1710 笔，含 ETF 份额分拆、红利、LOF 申购/转入、逆回购、银行转账）。

## 一、转换（本地电脑）

```bash
cd backend
uv run --with pdfplumber python scripts/jgd_pdf_to_csv.py <交割单.pdf> -o tx.csv
```

输出要点（**导入前必读**）：

| 输出项 | 含义 | 处理 |
| --- | --- | --- |
| `导入行数（聚合后）` | 聚合去重后的行数（日内同价成交会合并） | — |
| `推算初始现金` | 期末余额 − 回放增量（**仅首次导入需要**，用于设账户初始资金） | 首次导入时设置 |
| `各代码最终股票余额` | 对账锚点 | **抄下来**，导入后核对 |
| `警告:` 行 | 期初持仓合成 / 未知业务 / 未配对股份转入 | **停下人工确认**再导入 |

## 二、上传（本地 → VPS）

```bash
scp tx.csv 114.132.239.95:/tmp/tx.csv
ssh 114.132.239.95 "docker cp /tmp/tx.csv deploy-wws-1:/tmp/tx.csv"
```

## 三、导入（VPS 容器内）

```bash
# 首次使用前把脚本放进容器（或重建镜像使其内置）：
ssh 114.132.239.95 "docker cp /home/ubuntu/wws-adviser/backend/scripts/import_settlement.py deploy-wws-1:/tmp/"
ssh 114.132.239.95 "docker exec deploy-wws-1 python /tmp/import_settlement.py /tmp/tx.csv --username luc"
```

脚本走 service 层（预览 → 有错误即中止 → 确认），复用导入器的全部校验、
指纹去重与审计，**无需 HTTP 登录密码**。

## 四、对账

导入后核对两件事（网页持仓页，或让助手从 VPS 拉）：

1. **现金** = 交割单末笔"资金余额"（允许 ±0.01 价格舍入差）
2. **持仓数量** 与转换器输出的锚点逐一相同

## 首次导入的初始资金设置

首次导入前需把账户初始资金设为转换器的"推算初始现金"（等价口径：含银行
转入/转出折算、期初持仓虚拟购入成本吸收，保证回放期末现金精确对齐交割单）。
该步骤需要直接改库，找助手执行，例如：

```python
account.initial_cash_minor = to_scaled_int(Decimal("<推算初始现金>"))
```

## 边界与注意事项（重要）

1. **每次只导"上次之后"的新区间**。同一份 CSV 重复导入安全（指纹去重）；
   但**区间重叠的不同 PDF 会双计**——不同区间边界的聚合会产生不同指纹，
   重复交易不会被识别为重复。券商导出时把起始日期设为上次导入的截止日。
2. **警告行不静默**：出现"期初持仓/未知业务/股份转入未配对"警告时转换器
   已按保守策略处理并要求人工确认，不要无视。
3. **成本口径**：期初持仓（窗口前已有）按首行价格代理成本，建议后续导出
   更长周期交割单覆盖真实成本。

## 转换器处理规则摘要

| 交割单业务 | 处理 |
| --- | --- |
| 证券买入 / 证券卖出 | 直接映射（费用 = 手续费+印花税+其他杂费） |
| ETF份额分拆 | 拆股（零成本增数） |
| 红利入账 | 分红（qty=1 价格=金额；qty>0 时价格=金额/qty） |
| 上证LOF申购 / 开放基金申购 | 买入 |
| 股份转入（5 日内有同代码申购） | 跳过（份额到账配对，防双计） |
| 股份转入（未配对） | 0 成本买入 + 警告 |
| 银行转账 / 逆回购 / 股息差异 / 指定登记 | 不导入，折入初始现金 |
| 日内同价重复成交 | 聚合为一行（数量/费用求和，保指纹唯一） |

**同日时间序**：PDF 同日行序不可靠（实测既非正序也非倒序），转换器按
**股票余额链**重构（每行 before = after − 增减，链头 = before 不在任何
after 中）；余额环（日内买N卖N回起点）按"买入优先"回退——保证回放
无负持仓，极少数真·先卖场景仅均价微偏（余额列物理不可分辨）。

## 故障排查

| 症状 | 原因与处理 |
| --- | --- |
| 导入报 `卖出数量超过持仓` | 转换器版本过旧（无余额链排序）——更新后重新转换导入 |
| 预览错误行 `未知买卖方向` | 券商新增业务类型——在 `_OP_MAP`/`SKIP_OPS` 中补充映射 |
| 现金对账差几分钱 | 价格三位小数舍入累积（实测 1635 行差 0.005）——可接受 |
| 持仓数量不符 | 检查是否有未处理的"股份转入"警告行 |
