# ADR-0014：市场环境数据域——指数/板块资金流/外围市场采集范围与多源直连

> 状态：Accepted（2026-11-16 用户确认，批次 A/B 交付）
> 日期：2026-11-16
> 关联：PRD §20（标的范围）· 技术架构 §8 · [5_DATA §11.2/§12](../dev-guide/5_DATA_INGESTION_AND_QUALITY.md) · [0_INDEX §7.1](../dev-guide/0_DEVELOPMENT_GUIDE_INDEX.md) · ADR-0013

## 上下文

用户提出**整体市场环境研究**需求，需要四类数据：

1. A 股大盘各类指数（上证/深成/创业板/科创 50 等宽基 + 风格指数）与两市成交量；
2. 活跃板块榜单 + 板块主力净流入/净流出；
3. 外围市场：美股三大指数（含盘前/盘后参考）、日经 225、KOSPI、恒生/恒生科技。

现状约束与事实：

- 0_INDEX §7.1 已确认**标的范围 = A 股 + 场内 ETF**；市场环境数据不是投资标的，
  塞进 instruments/portfolio 域会污染持仓账本与标的搜索。
- 5_DATA §11.2 已确认 **MVP 数据源 = AKShare**；但生产适配器早有绕库直连先例——
  `akshare_quote.py`（VPS 实测全市场快照触发东财 WAF，改东财 push2 单股 + 腾讯兜底）、
  `akshare_document.py`（akshare 公告接口参数语义不符，改东财公告中心）。该先例此前
  未制度化。
- 所需端点已在另一项目 niuone（本地 D:\YQ_SOURCE_CODE\N_PROJ\niuone）生产验证：
  腾讯 `qt.gtimg.cn` 批量指数、新浪 `hq.sinajs.cn` 全球指数与全球期货（美股期货作
  盘前参考）、东财 `push2his` 指数日 K、东财 `push2delay clist` 板榜（涨幅/成交额/
  主力净额同源）。含多域名轮换与降级链的工程经验。
- 单用户国内 VPS 部署（ADR-0013），IP 风控敏感，不能复制 niuone 的高频全市场扫描。

## 决策

1. **新增「市场环境」独立数据域**：模块 `modules/market_env/` + 端口
   `ports/market_env.py`（`IndexQuoteProvider` / `IndexBarProvider` /
   `SectorFlowProvider`）。指数与板块**不注册**为 instruments；不进 portfolio/
   watchlist/建议任何持仓链路。
2. **数据源：公开接口多源直连**（腾讯主源 + 新浪/东财按端口各定主备），端口契约
   保持供应商无关。本 ADR 同时把「akshare 库之外直连公开免费接口」的既有先例收编
   为授权实现方式——**仅限公开、免费、无认证接口**；带 Key 的付费源（如问财）
   不在授权内，若引入另立 ADR。AKShare 作为既有五类别（quote/bar/nav/calendar/
   document）MVP 源的决策不变。
3. **采集频率按研究型数据定**：指数快照交易时段 5 分钟、板块资金流 30 分钟、
   指数日 K 收盘后一批、外围市场晨报前一批（08:10）+ 收盘后可选一批。
   日请求量约 70–100 次。
4. **类别与可观测性**：`source_health`/`ingest_items` 新增类别 `index_quote` /
   `index_bar` / `sector_flow`（Category 枚举扩展）；`quality_status` 六态照用；
   新鲜度阈值按类别新增命名常量（研究级，宽于盘中行情 180s）。
5. **消费边界**：市场环境数据仅作研究/报告上下文（晨报「市场环境」段、研究模块
   输入）。**不参与**凯利/建议计算；其新鲜度与质量状态**不触发** PAUSE_ADVICE 的
   既有数据合格判定（那是交易级数据的质量门）。

## 备选方案

- **A. 指数注册为 `instruments(kind=index)` 复用 `market_records`**——放弃：
  instruments 是投资标的注册表（watchlist/positions/搜索共用），混入指数污染全部
  消费面；`market_records` 的复权语义（adjustment_type）对指数无意义。
- **B. 全部走 akshare 库接口**——放弃为主源：VPS 实测全市场类接口触发东财 WAF
  （既有教训）；且美股盘前盘后、板块主力净额榜单的字段口径 akshare 覆盖不全。
  个别端点（如交易日历）仍可用 akshare，属适配器内部实现选择。
- **C. Tushare 付费源**——放弃：单用户成本不合理；板块资金流/美股期货覆盖不全。
- **D. 复制 niuone 30 秒级全市场宽度采样**——放弃：数据量与风控代价和单用户
  研究需求不匹配；两市成交量由指数快照 amount 汇总即可。

## 正负影响

**正向：**
- 填补市场环境研究数据缺口（现有 news 类别之外的最大空缺面之一）；
- 端点全部经 niuone 生产验证，降级链/解析器可移植，落地风险低；
- 独立域 + 类别扩展，既有质量/观测制度（5_DATA §3/§12）零改动复用；
- 把「绕库直连」先例显式制度化，消除悬空状态。

**负向 / 代价：**
- 三新表 + 四适配器，维护面扩大；
- 直连公开接口无 SLA，依赖降级链与 cassette 契约测试兜底；
- 美股盘前/盘后字段口径需实现期 cassette 实测确认（开放点，见 5_DATA §13）；
- 直连源的合规口径需在下次数据源条款复核（10 号 §8.5 口径）纳入重评。

## 迁移条件

- **对外服务/商用**：市场环境直连源与 AKShare 一并按 5_DATA §11.2 升级触发条件
  重评授权源（Tushare/米筐）。
- **需要板块成分股映射或分钟级量能 profile**：作为本域端口扩展（新增 Provider），
  不改既有表结构语义。
- **上游接口长期失效且无兜底**：按 5_DATA §11.2 升级路径切换适配器实现，端口与
  流水线不变。
