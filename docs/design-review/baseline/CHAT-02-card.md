## 2. 布局结构

```
1. PageHeader（title「建议详情」+ back）
2. 动作与状态卡（动作徽标 ACTION_META + 状态角标：有效/已过期/已失效
   + 代码 · 信号 + 生成/有效期时间戳）
3. 目标区间条卡（仅发布形态：0–100% 刻度水平带 primary/40 + 区间端点一位小数
   + 金额区间/建议手数 MetricCard；手数缺失注明「无法安全取整」）
4. 原因与标记（降级原因码中文释义逐条；suspend 形态 warning 色显式列类别）
5. 凯利折叠区（摘要「理论 X% → 风控后 Y～Z%」；展开每步 trail
   kind/note/before→after；固定诚实旁注一行）
6. 解读（model_explanation 有则显）
7. 事实和证据（evidence IDs 列表；空则「无（暂停形态不携带关键数字）」）
8. 建议评价（已评价：结论 VERDICT_NAMES + 窗口收益一位小数 + 评价时间；
   未评价：如实「待评价」）
9. 免责尾注 + DataFooter（截至 valid_from · 来源 advice/<id8> · 有效期至 expires_at）
```

- 栅格/分栏：单列；区间条卡内 MetricCard 两列
- 滚动行为：整页滚动；凯利区默认折叠（chevron 旋转）
- 桌面差异：同宽单列
