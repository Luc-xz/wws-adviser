# 基准卡：AUTH-01 登录

## 1. 参考稿

- 移动：`stitch/mobile/AUTH-01-mobile.html`（最终版）
- 桌面：`stitch/AUTH-01-desktop.html`（最终版）

## 2. 布局结构（从稿人工提取）

```
1. 品牌区（Logo + 产品名，垂直居中偏上）
2. 登录卡片（用户名 / 密码 / 主按钮「登录」）
3. 辅助说明（首次使用提示——CLI 建号，无公开注册）
```

- 栅格/分栏：单列，卡片宽 ≤400px 居中；移动满宽 - 2×16px 边距
- 滚动行为：无滚动（一屏内）
- 桌面差异：卡片居中，品牌区放大，背景可用品牌弱背景 `brand.soft`
